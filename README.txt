# Nairi & Lolita — wedding RSVP

## Структура

- `public/index.html` — сайт
- `public/intro.mp4` — видео
- `public/photo.jpeg` — единственная фотография
- `server.js` — сервер RSVP
- `.env` — SMTP-настройки (создай из `.env.example`)

## Запуск на компьютере

1. Установи Node.js.
2. Открой терминал в этой папке.
3. Выполни:

   npm install

4. Создай `.env` на основе `.env.example` и впиши SMTP-данные своей почты.
5. Запусти:

   npm start

6. Открой:

   http://localhost:3000

## Важно

Письма отправляются сервером на `ll0393207@gmail.com`.
Для реальной работы сайта для гостей сервер нужно разместить на хостинге. Пароль от почты нельзя вставлять в `index.html`.
